Hiyd

Hiyd captures highlighted text and saves it as a quote in a markdown file ready for a Jekyll blog. Use the right-click context menu on any selected text to save it.

How to use:

  • Select any text on a webpage
  • Right-click and choose "Hiyd Capture"
  • Choose where to save the markdown file
